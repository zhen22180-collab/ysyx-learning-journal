Project context

一生一芯是什么

一生一芯是中国科学院大学计算机科学与技术学院和中国科学院计算技术研究所于 2019 年发起的开源处理器芯片设计实践项目。它强调完整链路：从程序运行机理、 模拟器和基础设施，到处理器核、SoC、操作系统运行与工程验证。

它的价值不只是“学过处理器”，而是能展示如何把抽象课程知识变成可复现的 commit、测试、波形、性能数据和阶段性复盘。

开源芯片训练

以 RISC-V 和系统级验证为主线，把体系结构、编译运行环境和硬件实现连接起来。

项目制证据

适合持续沉淀日志、实验报告、bug 复盘、测试结果和阶段性 demo。

研究兴趣

自然连接计算机体系结构、嵌入式系统、EDA、操作系统和硬件/软件协同设计。

Learning roadmap

六个月学习路线

下面的路线偏向“可复现产出”：每个阶段都留下能被他人检查的证据，而不是只写“学习了某知识点”。

01

环境与计算机系统基础

搭建 Linux/WSL、Git、C/C++、Makefile、GDB 和 verilator 记录。输出环境复现文档。

02

NEMU / 程序运行机理

用模拟器理解指令、内存、异常和设备抽象。输出 bug diary 与关键函数阅读笔记。

03

RTL 处理器核

实现单周期或流水线 CPU，关注仿真、波形、指令测试和差分测试。输出波形截图和测试矩阵。

04

SoC 与外设

连接总线、存储、UART、timer 等模块，形成可运行软件栈的最小系统。输出系统框图。

05

操作系统与应用

运行更复杂的软件负载，记录失败、调试路径、性能瓶颈和正确性验证。

06

项目总结沉淀

整理英文项目页、关键技术说明、复盘文章和方向索引，把工程经历沉淀成长期可维护的资料。
