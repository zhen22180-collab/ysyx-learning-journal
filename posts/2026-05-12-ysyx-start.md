# 从一生一芯开始：建立可复现的学习日志（Codex写的）

## 背景

我准备把“一生一芯”作为接下来一段时间的主线项目，用它连接计算机系统、处理器设计、操作系统和硬件/软件协同设计。这个博客会记录每一周的学习证据：读过什么、实现了什么、哪里失败、如何验证。

## 为什么选择它

一生一芯的公开资料强调完整处理器芯片实践链路。这类经历可以帮助我沉淀三个层面的能力：

* 系统理解：从程序运行、模拟器、ISA 到操作系统和硬件实现。
* 工程方法：用 commit、测试、波形、报告和复盘留下可复现证据。
* 研究兴趣：把“喜欢底层”具体化为体系结构、EDA、嵌入式系统或 HW/SW co-design 的问题。

## 第一阶段目标

1. 搭建开发环境，记录可复现命令。
2. 阅读官方项目介绍和课程文档，整理术语表。
3. 建立每周日志模板，固定输出问题、实验、证据、下一步。
4. 开始准备英文项目 README 和技术摘要。
